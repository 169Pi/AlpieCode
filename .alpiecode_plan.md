# AlpieCode Task Plan

**Deliverables:**
1. `calculator.py` - A Python CLI calculator with arithmetic operations
2. `test_calculator.py` - Unit tests for the calculator

**Files to create:**
- `calculator.py` - Main calculator module with:
  - `add(a, b)`, `subtract(a, b)`, `multiply(a, b)`, `divide(a, b)` functions
  - `calculate()` function that parses CLI input
  - Proper error handling for division by zero and invalid input
  
- `test_calculator.py` - Unit tests with:
  - Test cases for all arithmetic operations
  - Test cases for edge cases (division by zero, invalid input)
  - Test cases for CLI parsing

**Verification:**
- Run `python -m pytest test_calculator.py` to verify all tests pass
- Test the CLI manually with various inputs
