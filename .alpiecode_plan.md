# CLI Calculator with Tests

## Deliverables
1. **calculator.py** - Main calculator module with CLI interface using click
2. **calculator/__init__.py** - Package init file
3. **test_calculator.py** - Comprehensive test suite

## Features
- Basic arithmetic: add, subtract, multiply, divide
- Advanced operations: power, modulo, square root, factorial
- Support for multiple numbers and operations
- Clean CLI interface with help text
- Error handling for invalid inputs and division by zero

## Files to Create
1. `src/calculator/__init__.py` - Package initialization
2. `src/calculator/calculator.py` - Calculator logic and CLI
3. `test/test_calculator.py` - Test suite

## Verification Checks
- Calculator compiles without errors or warnings
- CLI help displays correctly
- All basic operations work (add, sub, mul, div)
- Advanced operations work (pow, mod, sqrt, factorial)
- Error handling works (division by zero, invalid input)
- All tests pass (pytest)
