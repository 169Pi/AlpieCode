# AlpieCode Task Plan

Create a Python CLI calculator with:
1. calculator.py - Core calculator module with arithmetic operations (+, -, *, /)
2. main.py - CLI interface for user interaction
3. test_calculator.py - Unit tests covering all operations and edge cases

The calculator will:
- Support basic arithmetic operations
- Handle division by zero gracefully
- Accept command-line arguments and interactive input
- Display results in a clean format
