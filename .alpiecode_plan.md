# AlpieCode Task Plan

Create a Python CLI calculator with:
1. Calculator module (calculator.py) with arithmetic operations: add, subtract, multiply, divide, power, modulo, square root
2. CLI interface (cli.py) for command-line usage
3. Unit tests (test_calculator.py) covering all operations including edge cases
4. Main entry point (main.py) to run the CLI

Verification:
- All tests pass with pytest
- CLI works with various inputs
- Edge cases handled (division by zero, negative roots, etc.)
